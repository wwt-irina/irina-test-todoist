# Java Hello World Application

A simple Java application that prints "Hello, World!" to the console.

## Prerequisites

- Java Development Kit (JDK) 8 or higher

## How to Compile

Navigate to the `java-hello-world` directory and compile the Java file:

```bash
javac src/HelloWorld.java
```

This will create a `HelloWorld.class` file in the `src` directory.

## How to Run

After compiling, run the application with:

```bash
java -cp src HelloWorld
```

You should see the following output:

```
Hello, World!
```

## Clean Up

To remove the compiled class file:

```bash
rm src/HelloWorld.class
```
